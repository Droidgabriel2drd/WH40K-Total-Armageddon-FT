# Python app

Scaffolded with **Grok Chat** for an efficient AI + human workflow.

## Quick start
```bash
python -m venv .venv
# activate venv, then:
pip install -e ".[dev]"
python -m src.main
```

## Test
```bash
pytest
```

## Grok
Project rules live in `AGENTS.md` and `.xgrok/`. Open the **Grok Chat** panel to work with the agent.
